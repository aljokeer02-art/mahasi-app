# محاسي — نظام المحاسبة العائلية

تطبيق ويب جاهز، مبني بـ Next.js ومرتبط بمشروع Supabase الخاص بك.

## تم إعداده مسبقاً
- ملف `.env.local` يحتوي على رابط ومفتاح مشروعك بالفعل — لا تحتاج تعديل شيء.
- قاعدة البيانات (11 جدولاً) تم إنشاؤها بالفعل في Supabase.

## خطوة إضافية مطلوبة قبل النشر
افتح ملف `step2_invite_function.sql` وشغّله في Supabase SQL Editor (نفس طريقة الملف الأول) — يفعّل ميزة دعوة أفراد العائلة.

## النشر على Vercel (مجاني)
1. ادخل إلى vercel.com وسجّل حساباً (يمكن عبر GitHub أو البريد).
2. اضغط "Add New Project".
3. ارفع هذا المجلد كاملاً (اسحبه أو استخدم خيار "Upload" إن توفر)، أو ادفعه لمستودع GitHub ثم اربطه.
4. Vercel سيكتشف أنه مشروع Next.js تلقائياً — لا تغيّر أي إعداد.
5. تأكد أن متغيرات البيئة `NEXT_PUBLIC_SUPABASE_URL` و `NEXT_PUBLIC_SUPABASE_ANON_KEY` منسوخة من ملف `.env.local` إلى إعدادات Vercel (Settings > Environment Variables).
6. اضغط Deploy وانتظر دقيقة — سيعطيك رابطاً مباشراً للتطبيق.

## أول استخدام
1. افتح الرابط، اضغط "حساب جديد"، سجّل ببريدك.
2. أنشئ "مساحة العائلة" (اسم اخترته أنت).
3. اذهب لـ "دليل الحسابات" وأنشئ الحسابات الأساسية (الصندوق، البنك، مصروفات، إيرادات...).
4. ادعُ أفراد عائلتك من صفحة "المستخدمون والصلاحيات" بعد أن يسجّلوا حسابهم الخاص.

## هيكل المشروع
```
app/            صفحات التطبيق (كل مجلد = رابط)
components/     مكوّنات مشتركة (الشريط الجانبي، الحماية)
contexts/       إدارة حالة تسجيل الدخول والمساحة الحالية
lib/            عميل الاتصال بـ Supabase
schema.sql      إعداد قاعدة البيانات (نُفّذ بالفعل)
step2_invite_function.sql   دالة دعوة الأعضاء (يجب تنفيذه)
```
